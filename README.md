PostgreSQL 外部表（Foreign Table） 是 “看起来像本地表，实际数据却存放在别的系统里” 的一张虚拟表。
你可以对它做 SELECT、JOIN、INSERT、UPDATE、DELETE，但数据不保存在 PostgreSQL 本地，而是由外部数据源（另一个数据库、文件、对象存储、API…）实时提供。
